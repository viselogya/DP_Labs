Такт  Участок / действие      Курс    v, м/с     ω, рад/с      Условие перехода
 0    A, загрузка             —       0          0            Стоянка 2 с
 1    A → B                   +π/2    0 → ≤0,15  + → 0¹       До B ≤ 0,025 м

 7    F → A                   +π/2    0 → ≤0,15  − → 0        До A ≤ 0,025 м
      Возврат к такту 0.

¹ Первый старт выполняется с курсом 0. В следующих циклах курс при
прибытии в A уже близок к +π/2, поэтому требуется лишь малая коррекция.

В таблице знак ω указан для номинальной геометрии. У каждого участка два
режима: при развороте v = 0, ω = ограниченное 2,4 × ошибка курса (±0,80).
При достижении |ошибка курса| ≤ 0,05 рад включается поступательное движение:
v = min(0,15; 1,2 × расстояние до цели) × cos(ошибка курса).
На ходу ω продолжает исправлять ошибку, а v уменьшается вблизи цели.
Когда |ошибка курса| превышает 0,25 рад, робот снова разворачивается на месте.
В контрольной точке v = ω = 0 минимум один такт контроллера.

Номинальные длины прямых: 0,90 / 2,20 / 0,90 / 0,90 / 2,20 / 0,90 м.
При постоянной скорости 0,15 м/с им соответствуют 6,0 / 14,7 / 6,0 /
6,0 / 14,7 / 6,0 с. Для поворота на 90° при постоянной скорости 0,80 рад/с
ориентир составляет 2,0 с. Фактические длительности движения зависят
от одометрии и замедления вблизи цели. По времени отсчитываются стоянки.
