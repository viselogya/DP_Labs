# Лабораторная работа 2.2 · Цикловое управление RoboCake Beginner

Робот перевозит условный груз между синей зоной загрузки и оранжевой зоной выгрузки. Расстояние между центрами зон составляет 2,20 м, длина пути в каждую сторону составляет 4,00 м. Между зонами робот выполняет как минимум два поворота. Загрузка и выгрузка моделируются остановками по 2 с. Порядок тактов и профили скоростей описаны в [cycle.txt](cycle.txt).

## Зависимости и запуск

Пакет рассчитан на Linux с ROS Noetic, Catkin, Python 3 и Gazebo Classic 11. Требуются пакеты `gazebo_ros`, `gazebo_ros_control`, `controller_manager`, `diff_drive_controller`, `joint_state_controller`, `robot_state_publisher`, `xacro`, `map_server`, `rviz`, `rospy`, `geometry_msgs`, `nav_msgs`, `sensor_msgs`, `tf` и `tf2_ros`.

В Catkin workspace должны быть установлены `robocake_description`, `robocake_controllers` и `robocake_gazebo` из RoboCake Beginner ревизии `ef4893ae410cc611604126bd3c798c527565b61d`. Родительский `scripts/fetch_robocake.sh` размещает и адаптирует исходники. Используется штатный `green.urdf.xacro` с `gazebo_ros_control`, штатные колёсные шарниры и конфигурация контроллера привода. Исходный YAML привода задаёт имена шарниров, тип контроллера и ковариации. Пределы скорости 0,15 м/с и 0,80 рад/с выбраны для этой лабораторной работы и заданы в её управляющем узле.

После подготовки Catkin workspace по инструкции родительского проекта доступны команды:

```bash
source ~/catkin_ws/devel/setup.bash
roslaunch lab2_2_cycle demo.launch
roslaunch lab2_2_cycle warehouse.launch gui:=false rviz:=false
roslaunch lab2_2_cycle map.launch
```

Команды запускают соответственно полный цикл, склад с управляемым извне роботом и просмотр одной карты. Запускайте один вариант за раз. В `demo.launch` доступны `gui`, `rviz` и `dwell` в секундах. В `warehouse.launch` доступны `gui`, `rviz` и начальная поза `x`, `y`, `yaw` в метрах и радианах. При сбросе симуляции перезапустите запуск целиком, чтобы переинициализировать интегратор и цикл.

## Интерфейс для 2.3

| Ресурс | Путь или имя по умолчанию |
| --- | --- |
| Пакет | `lab2_2_cycle` |
| Мир Gazebo | `$(find lab2_2_cycle)/worlds/warehouse.world` |
| Карта | `$(find lab2_2_cycle)/maps/warehouse.yaml` и соседний `warehouse.pgm` |
| Gazebo, робот, карта, одометрия и локализация | `launch/warehouse.launch` |
| Карта и опциональный RViz | `launch/map.launch` |
| Команда привода · `geometry_msgs/Twist` | `/cmd_vel` |
| Измеренные положения колёс · `sensor_msgs/JointState` | `/joint_states` |
| Одометрия · `nav_msgs/Odometry` | `/odom` |
| Карта · `nav_msgs/OccupancyGrid` | `/map` |
| Поза в карте · `geometry_msgs/PoseStamped` | `/warehouse/pose` |
| TF | `map → odom → base_link` |

Координаты `map` совпадают с горизонтальными координатами мира Gazebo. Размер карты 72 × 60 ячеек при разрешении 0,05 м. `origin: [-1.8, -1.5, 0.0]` задаёт положение нижнего левого угла растра в `map`. Начальная поза робота задаётся отдельно в launch. Свободная внутренняя область ограничена стенами на `x = ±1.70` и `y = ±1.40`. Центральный стеллаж занимает `[-0.35, 0.35] × [-0.40, 0.40]`. Центры зон расположены в `(-1.10, 0)` и `(1.10, 0)`. Допустимые оси проездов для маршрутного графа проходят по `x = ±1.10` и `y = ±0.90`. Цветные площадки свободны на карте и проезжаемы в Gazebo.

Для своей модели робота или собственных контроллеров можно загружать SDF и YAML непосредственно. `warehouse.launch` публикует глобальные имена из таблицы. Запуск собственной системы управления должен иметь единственного активного издателя команд движения.

## Узлы и проверка

- `odometry_publisher` считывает приращения непрерывных углов колёс из `/joint_states`. Радиус колеса составляет 0,022131 м, колея составляет 0,084918 м. Узел интегрирует движение по дуге и публикует `/odom` и динамический TF `odom → base_link`. Штатный дифференциальный контроллер публикует диагностическую одометрию в `/diff_drive_controller/odom`, публикация его TF отключена.
- `localization_publisher` связывает начало отсчёта одометрии с заданной позой запуска и выдаёт позу в `map`. Оценка зависит от проскальзывания и накапливает дрейф. `map_server` публикует фиксированную карту.
- `cycle_controller` разворачивается к следующей точке, проезжает к ней с коррекцией курса, останавливается в пределах 2,5 см и повторяет цикл. При отсутствии свежей позы он выдаёт нулевую скорость. Тайм-аут штатного привода составляет 0,25 с.

При демонстрации в Gazebo и RViz можно сопоставить положение робота со стенами и стеллажом и проверить чередование стоянок в двух зонах. `rostopic echo /cmd_vel` показывает повороты на месте и поступательное движение, `rostopic echo /warehouse/pose` показывает приближение к контрольным точкам. Во время подготовки пакета проверены только статические файлы. Моделирование и измерение повторяемости цикла остаются этапами демонстрации.
